    Console workspace — mockup

    A proposal to look at and click through. It doesn't connect to anything, and the fixtures are made up.

    • Grid fills the screen. Page title and help sentences are gone. The header is one row, and Show tools and Fixture library sit under Show.
    • One toolbar: layer tabs, Plan / Compact spacing, Fit and zoom, Lasso, Add, Select menu, View menu (Ghosts, Edit layout) and a Windows menu.
    • Windows: Controls opens docked on the right, so the grid fits beside it. Drag the dock's edge to make it wider or narrower. Float pops a window over the grid; Dock, or dropping it on the right edge, puts it back. Floating windows drag by the title bar and resize from the bottom-right corner. Collapse with the chevron, hide with ✕, bring back from Windows. Everything is remembered per browser.
    • Tiles: FID + short name, selection order number, SET / TEST / HL tags, colour swatch, intensity bar with its %. Pixel bars show their cells as segments you can pick.
    • Compact packs each row tight in plan order and drops empty rows; Plan keeps the MVR spacing. Fit zooms to show the whole layer.
    • Tests is its own tab with the same grid and the same selection.
    • Toggles show ON with a check, a thicker border and bold text, so colour is never the only sign.

    Try it: click tiles (Ctrl/⌘ or Add to add), drag on empty grid with Lasso, move the Dimmer fader, pick a colour, then switch to Tests and turn a test on.
