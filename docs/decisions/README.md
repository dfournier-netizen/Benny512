# Decisions

One file per durable decision: `NNNN-short-slug.md`, numbered in the order they
were taken.

A decision belongs here when it answers "why is it like this?" and the answer
should survive the next person who thinks it looks wrong. A session log entry
belongs in `../notes/`.

Each file states: the decision, the evidence or primary-text citation behind it,
what was rejected and why, and what would have to be true to revisit it. If a
decision is later reversed, the new file says which one it reverses and the old
file gets a line pointing forward — neither is deleted.

Seed these from `../notes/` as questions come up again, not by mining the whole
history at once.
