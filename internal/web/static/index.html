Send

Manual DMX control

Manual send overrides live console output

Circuit values 0–255. Every channel transmits live while you drag, zeros included — a channel pulled down to 0 goes dark immediately, it does not hold its last value. Park a channel to freeze it and protect it from a stray drag; a parked channel still transmits at its frozen value, park does not hand it back to a console. Confirm no board is patched to this universe before sending.

Settings

Network

Display only — every universe number shown or typed anywhere in Benny512 (Patch, Send, Devices, Rig Check, import previews) is renumbered from this base. Nothing sent on the wire or stored in the patch ever changes: if this is set to 1 and you enter universe 1, Benny512 still addresses wire universe 0, matching Art-Net's own 0-based numbering (Obsidian EN4 and Vectorworks number from 1, hence the choice). Nodes' port configuration still shows Art-Net's own raw Net/Sub-Net/Universe addressing, unaffected by this setting — see the Phase A notes.

Capture & logging

Appends every RDM/ToD exchange to this file as it happens, so a long bench session isn't limited by the in-memory buffer. Blank = disabled. Rotates automatically by size.
